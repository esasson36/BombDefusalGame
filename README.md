# Bomb Defusal Game

A text-based bomb defusal game built in **Python**,inspired by the game "Keep talking and nobody explodes", featuring randomized puzzles, logic-based challenges, and cryptography.

Players must solve a series of bomb modules by following instructions, interpreting clues, and submitting the correct answers to successfully defuse the bomb.

## Features

The game includes four puzzle modules:

### Wires
- Generates wires with different colors.
- Requires players to identify the correct wire to cut based on specific rules.
- Uses conditional logic to determine whether the selected wire is correct.

### Keypad
- Presents a keypad challenge involving symbols or values.
- Players must determine the correct answer using the module's rules.
- Uses randomized values and answer validation.

### Morse Code
- Challenges players to interpret messages encoded in Morse code.
- Incorporates encoded information and pattern recognition.

### Password
- Features password-solving challenges using the **Vigenère cipher**.
- Combines string manipulation and cryptographic logic to create puzzles.

## How to Play

1. Launch the Python program.
2. Follow the instructions presented in the terminal.
3. Solve the bomb defusal puzzles using the clues and module rules.
4. Submit your answers to determine whether each module has been solved.
5. Successfully complete the required challenges to defuse the bomb.

The game includes win/loss conditions and the ability to play again.
